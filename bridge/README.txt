ЗВУКОРЯД — тренажёр дикции + мост к Claude CLI
================================================

Что в архиве
  zvukoryad.html        — сам тренажёр
  zvukoryad-bridge.mjs  — локальный сервер без зависимостей. Он:
                          • открывает тренажёр по адресу http://localhost:8787,
                            где работает микрофон;
                          • передаёт запросы ИИ в ваш Claude CLI (через ваш вход в Claude);
                          • ставит и запускает Whisper (точное распознавание речи)
                            и Piper (живые голоса) — всё локально, по кнопке в Настройках.
  start-windows.cmd     — запуск на Windows
  start.sh              — запуск на macOS/Linux

Что нужно один раз
  1. Node.js 18 или новее: https://nodejs.org
  2. Claude Code: npm install -g @anthropic-ai/claude-code
     (или установщик с https://claude.com/claude-code, или расширение Claude Code
     в VS Code / Cursor — мост найдёт его сам).
  3. Один раз запустить `claude` и войти в свой аккаунт.

Запуск
  Windows:       двойной клик по start-windows.cmd
  macOS/Linux:   ./start.sh
  Браузер откроется сам: http://localhost:8787 (лучше Chrome или Edge).
  Когда файлы моста обновляются, он перезапускается сам.

Whisper и живые голоса
  Тренажёр → Настройки → «Распознавание речи» и «Озвучка».
  Если скачивание не проходит (блокировки), мост пробует ещё раз через
  системный прокси/VPN. Если и так не вышло — Настройки покажут прямые ссылки:
  скачайте файлы браузером и нажмите «Найти скачанные файлы» — мост заберёт
  их из «Загрузок» или с рабочего стола.

Параметры запуска
  --port 8788            другой порт
  --claude "путь"        свой claude(.exe), если его не находит автоматически
  --model sonnet         модель для разборов (по умолчанию — как в вашем CLI)
  --quick-model haiku    модель для быстрых ответов собеседника
  --no-open              не открывать браузер
  --new-token            сменить ключ доступа

Как подключаются другие люди
  Каждый запускает мост у себя — со своим Claude CLI и своим входом.
  Если тренажёр открыт не через мост (файлом или с сайта), в
  «Настройки → ИИ: Claude» впишите адрес моста и ключ из окна моста.

Где что хранится
  ~/.zvukoryad/            ключ моста, настройки, Whisper и голоса Piper
  Прогресс тренировок      в браузере (перенос — Настройки → Данные)

Безопасность
  Мост слушает только этот компьютер (127.0.0.1) и отвечает лишь на запросы
  с ключом. Claude запускается без инструментов (не читает и не меняет файлы).
  Записи голоса не покидают компьютер: в Claude уходит только текст.
