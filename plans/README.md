1. **001** — первым: вводит токены `--ease-out`, `--ease-in-out`, `--dur-*`, на которые опираются 004, 006, 007.
2. **002**, **003**, **005** — независимы, в любом порядке.
3. **004**, **006**, **007** — после 001.

Номера строк в планах указаны для коммита `bfc29a5`. При выполнении по порядку строки в `src/style.css` сдвигаются на 3 после 001 и ещё на несколько после 003 — ищите правила по тексту, а не только по номеру строки.
